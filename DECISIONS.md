## Что требует задание → чем закрыто

| Требование задания | Решение в репозитории |
|---|---|
| Асинхронный веб-фреймворк (например FastAPI) | FastAPI + uvicorn, `app/main.py` |
| Миграции для базы данных | Alembic (`alembic/`), автогенерация из `app/models.py` |
| PEP8 | `ruff` с `select = E,F,I,UP,B`, `line-length = 120` (`pyproject.toml`) |
| Конкурентность: параллельные операции по одному кошельку | Инварианты INV-1…INV-3 и допустимые механизмы — SPEC.md §4 |
| Приложение в Docker + БД в Docker + одна команда | `docker-compose.yml` (db + app), `Dockerfile` |
| Эндпоинты покрыты тестами | `tests/` + `pytest`; критерии приёмки AC-1…AC-6 |
| Решение на GitHub | план работ — SPEC.md §9 |

## Пере-настраиваемые решения (выбрано по умолчанию, меняется легко)

| Решение | Значение по умолчанию | Альтернатива и что меняет |
|---|---|---|
| Тип денег | `NUMERIC(20,2)` + `Decimal` в Python | целые минорные единицы (копейки): проще атомарная арифметика в SQL, но API отдаёт копейки |
| Формат баланса в JSON | строка `"1000.00"` | число: клиент получит float и потеряет точность на больших суммах |
| Кошелёк по неизвестному UUID | `404` + `scripts/seed.py` для создания кошельков | автосоздание при первом `DEPOSIT`: удобнее для проверки curl-ом, но скрывает «кошелька нет» как ошибку |
| Порт API | `127.0.0.1:8000` | любой свободный |
| Порт Postgres на хосте | `127.0.0.1:55432` | `5432` — так было бы по умолчанию, но на этой машине порт занят локальным PostgreSQL 18 и контейнер не смог бы его опубликовать |
| Недостаточно средств | `409 Conflict` | `400 Bad Request` |
| Версия Python | 3.12 в контейнере, 3.11 локально | `pyproject.toml` разрешает ≥3.11 |
| Где гонять повседневный цикл | контейнер `db` + `pytest` на хосте | своя локальная база PostgreSQL 18 (уже стоит) вместо контейнера: тогда Docker нужен только для финальной проверки «одной командой» |
